## 两条核心产品链路（设计校验点）
1. **首次使用**：首页 → 选「川菜」→ 抽一签 → 鱼香肉丝 → 查看菜谱
2. **长期使用**：添加菜谱 → 创建签池 → 加入菜谱 → 每天抽签 → 看历史 → 完善菜谱库

真实产品核心 = **「拥有抽签仪式感的个人菜谱管理器」**：抽签负责有趣，菜谱库负责留存，自定义签池负责个性化。
